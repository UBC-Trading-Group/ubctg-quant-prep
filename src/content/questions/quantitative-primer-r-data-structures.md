## Problem

What are some data structures used in R?

## Hint 1

Mention both homogeneous and heterogeneous structures.

## Hint 2

Vectors, matrices, lists, and data frames are the classics.

## Solution

Common R data structures include:

- atomic vectors: homogeneous one-dimensional data,
- matrices: homogeneous two-dimensional data,
- arrays: homogeneous multi-dimensional data,
- lists: heterogeneous collections,
- data frames: tabular data where columns can have different types,
- factors: categorical variables with levels.

In interviews, it helps to emphasize that many R operations are vectorized and that a data frame is essentially a list of equal-length columns.
